# UI-only package recipes

Each recipe produces one independently revisioned `.aklp` envelope. English stays
embedded; these optional artifacts contain only a UI catalog, MIT text and the
translation notice. No input dictionary/rules or conversion readiness is claimed.

The revision-1 candidates signed on 2026-09-12 are recorded under
`target/ui-package-candidates-20260912-01/verification.json`. Preserve those exact
artifacts; a changed published package must use a new revision, never different
bytes under an already-published identity/revision. Draft linguistic/native UI
acceptance is still pending. A signed release catalog and explicit publication
authorization are separate from local package signing.
