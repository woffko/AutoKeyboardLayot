- Russian package revision 4 (runtime API 2): opt-in single-letter targets
  `а, и, в, к, о, с, у, я`. The proposed interjection `э` was excluded by the owner.

New Russian data requires an API-2 application. Older applications should first
install the updated application, then use **Input languages -> Add language** to
refresh, select Russian, download and install it. The single-letter setting in
General must be enabled and saved using Apply.

The owner explicitly authorized changing the repository visibility to public.
This is necessary for the existing unauthenticated WinHTTP download flow. While
the repository was private, both old and new anonymous release URLs returned 404.
